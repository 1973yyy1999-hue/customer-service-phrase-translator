# 客服语气翻译器

面向中文客服的桌面浏览器工具。内置 76 条话术和 9 种语种，支持自定义语种。匹配结果在外文下方显示中文直译，复制按钮只复制外文。

## 在 Windows 使用

1. 下载或克隆仓库。使用 ZIP 时先解压。
2. 用 Edge 或 Chrome 打开 `客服语气翻译器.html`。选语言，输入「退款」可查看相关主题词条。输入「退款审核中」可进一步匹配业务状态。
3. 在「常用语词库」新增、编辑、删除或导入旧版备份。换浏览器或切换到本机服务前，可先导出词库备份。

[查看中文使用手册](使用手册.pdf)

## 用 Excel 批量维护

在「常用语词库」点「导出 Excel」，用 Excel 编辑后保存为 `.xlsx`，再点「导入 Excel」。表内的「填写说明」列出了完整规则。

- 保留「话术」表的第一行列名。修改已有话术时保留词条编号。新增话术时可留空，导入会先按中文原文匹配，找不到同句才新增。
- 导入按表内记录合并。要删除某条话术，在该行的「操作」列填写「删除」并保留编号。导入后可以撤销。
- 现有译文、直译或关键词单元格留空会清空该字段。省略整列会保留已有值。请填写纯文本。

## 添加自定义语种

在「设置 → 自定义语种」填写显示名称与国际语言代码，例如「泰语」和 `th`。API 翻译要求可选，例如「使用泰国客服敬语」。保存后可逐条填写译文，也可重新导出 Excel 批量填写。

也可以在「语种」表加入新语种，再在「话术」表加入「泰语译文 [th]」和「泰语中文直译 [th]」两列。用方括号中的代码关联语种。新增语种可用于 API 实时翻译，浏览器本地翻译依所用浏览器的语言包而定。

## 启用实时翻译

浏览器本地翻译可在支持该功能的桌面版 Chrome 中开启。使用 API 客服翻译时，先安装 Python 3.10 或更新版本，再在 Windows 运行 `启动翻译服务-Windows.bat`，或在 Mac 运行 `启动翻译服务-Mac.command`。保持终端窗口开启，从本机网页的「设置」选择翻译模式和模型。

API 支持 DeepSeek、OpenAI、Google Gemini、通义千问及自定义兼容接口。启用后在设置中填入自己的 API 密钥。

## 编辑内置词库

- `src/phrases.txt` 保存中文原句、关键词和九种外文译文。
- `src/glosses.txt` 保存各语言需要单独表达的中文直译。
- `src/app.js` 和 `src/shell.html` 保存页面逻辑和结构。

修改源文件后运行 `node scripts/build.cjs`，重新生成可直接打开的 HTML。

Excel 功能使用 SheetJS Community Edition 0.20.3。原版浏览器脚本和 Apache 2.0 许可证见 [vendor/sheetjs](vendor/sheetjs)。
